# 沛警智枢前端终版开发计划

## 1 基线与终版范围

- 代码基线：`origin/codex/generic-agent-platform`，实施分支 `peixian-ui-final`。
- 需求基线：需求规格说明书 V1.0 与 `前端原型图/图片1.png` 至 `图片12.png`。
- 民警端仅保留账号登录和智能研判。
- 智能研判内提供能力选择、文件、深度研判、Skill Creator、执行轨迹及证据链。
- 管理端仅保留模型管理、用户与部门、调用审计。
- 官方 Skill 和插件使用管理员隐藏的“能力配置”入口维护，不进入主导航。
- 删除我的智能体、Skill 中心、插件中心、插件管理、Skill 审核、短信登录、联网搜索、右侧推荐区及相关插件区。

图9至图12中遗留的“插件管理、Skill审核”侧栏不属于最终范围。个人 Skill 通过能力弹窗完成选择、创建、编辑、测试和删除，不建设独立页面。

## 2 页面与接口

| 页面 | 主要功能 | 接口 |
| --- | --- | --- |
| 登录 | 账号密码、首次改密、角色路由 | `/auth/login`、`/me`、`/me/password`、`/auth/logout` |
| 智能研判 | 会话、模型、消息、文件、能力、深度研判 | `/sessions`、`/models`、`/files`、`/capabilities` |
| 能力弹窗 | Skill/插件检索、个人 Skill 选择和管理 | `/capabilities`、`/skills` |
| Skill Creator | 从需求或当前对话生成、编辑、测试、保存 | `/skill-drafts/*` |
| 研判过程 | 结构化步骤、状态、耗时和错误 | `/sessions/{sid}/runs/{runId}`、`.../events` |
| 证据链 | 结论、轨迹、场所、同行和分析链 | `.../evidence`、`.../rerun`、`.../report` |
| 模型管理 | 增改、测试、启停、默认模型 | `/admin/models` |
| 用户与部门 | 用户、警号、职务、权限、部门树 | `/admin/users`、`/admin/departments/*` |
| 调用审计 | 查询、详情、导出 | `/admin/invocations` |
| 能力配置 | 官方能力增改、启停、依赖和测试 | `/admin/capabilities` |

## 3 数据与权限原则

- `system_role` 负责系统授权；`position` 负责警务职务展示和筛选。
- 用户生成 Skill 固定为个人范围；官方能力由管理员直接配置，不经过审核中心。
- 前端不直接请求公安数据源。人员、关系、轨迹、涉案、涉警等接口均通过后端工具适配层调用。
- 运行事件不得返回模型内部原始思维过程，仅返回可审计的步骤、输入输出摘要、记录数和错误。
- API Key、公安接口凭证只写不读，不进入浏览器响应和日志。
- 公安接口未具备正式契约时使用同结构 Mock，页面不得依赖固定演示数据字段。

## 4 开发阶段与验收门槛

1. **认证与框架**：完成终版品牌、账号登录、首次改密、角色路由和导航删减。
2. **研判主链路**：完成会话、模型、消息、文件、能力和深度研判模式。
3. **Skill Creator**：完成两种生成方式、草稿编辑、测试、保存和个人 Skill 管理。
4. **运行与证据**：完成执行轨迹、证据抽屉、重新研判和报告导出。
5. **管理端**：完成模型、用户部门、调用审计和隐藏能力配置。
6. **业务联调**：按接口台账逐项将 Mock 替换为正式公安接口。
7. **验收**：完成权限隔离、敏感信息脱敏、Chrome/Edge 桌面分辨率、异常和恢复测试。

每阶段必须通过 TypeScript 类型检查、前端构建、后端单元测试和对应页面的人工验收后方可进入下一阶段。

## 5 完成定义

- 被取消模块在导航、路由、空状态和网络请求中均不出现。
- 普通用户无法访问任何管理接口；管理员不能越权读取业务正文。
- 会话、个人 Skill、文件按用户隔离。
- 研判报告、证据链和调用审计通过同一 `run_id` 可追踪。
- Mock 与正式业务接口使用相同响应结构，切换数据源不修改前端。
